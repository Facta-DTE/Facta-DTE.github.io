# Facta DTE public application policies

Static public pages for application privacy policies and support. The hymnal developer is Marvin Quevedo, matching the existing Google Play listing.

- Home: https://facta-dte.github.io/
- Hymnal privacy policy: https://facta-dte.github.io/himnario/privacidad/
- Authorized advertising seller record: https://facta-dte.github.io/app-ads.txt

GitHub Pages serves the root of the `main` branch. No build step, JavaScript, analytics, advertising, external fonts or client-side cookies are included in this website. GitHub operates the hosting infrastructure under its own privacy practices.

The policy describes the reconstructed hymnal version 3.0. Keep its disclosures aligned with the shipped application, its advertising configuration and the Google Play Data safety declaration. Android system backups are enabled in the current application manifest. Support uses the application-specific contact address selected by the owner: himnario@factadte.com.

Only the files intended for this public site belong in this repository. Do not add application source, song databases, private keys, account exports or internal recovery reports.
